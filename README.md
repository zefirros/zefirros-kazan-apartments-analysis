# Рынок недвижимости Казани - студии и однокомнатные квартиры

<img width="1848" height="971" alt="Анимация" src="https://github.com/user-attachments/assets/92e21159-30fa-4e29-aed8-4704f9e99f93" />


Разведочный анализ и проверка статистических гипотез по рынку **студий** и
**однокомнатных квартир** в Казани на данных объявлений Avito.

## Цели проекта

- Сколько стоит типичная студия и типичная однушка в Казани?
- Какие районы доступнее, а где сосредоточен премиум-сегмент?
- Какие факторы (метро, возраст дома, этаж, ЖК) сильнее всего влияют на цену за кв.м.?

## Структура репозитория

```text
├── kazan_apartments_market_analysis.ipynb   # Очистка и разведочный анализ (EDA)
├── hypothesis_tests.ipynb                   # Проверка гипотез
├── dashboard.xlsx                           # Дашборд в Excel
├── data/
│   ├── avito_kvart.txt                      # Исходный датасет
│   └── avito_kvart_clean.txt                # Очищенный датасет
└── README.md
```

## Данные

- **Источник:** объявления Avito, Казань и пригороды
- **Исходный объём:** 6 594 записи
- **После очистки:** 5 593 записи (удалены строки с пустыми ключевыми полями, пригородные районы и выбросы по цене и площади)
- **Формат:** `.txt` с разделителем `|`

| Колонка | Тип | Описание |
| :--- | :--- | :--- |
| `layout` | категориальный | `студия` / `однушка` |
| `type` | категориальный | `Новостройка` / `Вторичка` |
| `district` | категориальный | Район Казани или пригорода |
| `residential_complex` | категориальный | Название ЖК |
| `area` | float | Площадь, кв.м. |
| `total_floors` | float | Этажность дома |
| `floor` | float | Этаж квартиры |
| `year_built` | float | Год постройки дома |
| `completion_year` | float | Год сдачи новостройки |
| `metro_walk` | категориальный | Ближайшие станции и время ходьбы одним текстом |
| `metro_stations` | категориальный | Те же станции без времени |
| `price` | object | Цена в рублях - хранится строкой из-за `₽` и пробелов |
| `price_per_m2` | float | Цена за кв.м., ₽ |

## Ноутбуки

### `kazan_apartments_market_analysis.ipynb` - очистка и EDA

1. **Подготовка:** удалили пустые строки, распарсили `price` из строки, привели типы, нормализовали названия районов, вытащили ближайшее метро, объединили `year_built`/`completion_year` в `age`, убрали выбросы, разметили `is_premium`.
2. **Общая картина рынка:** распределение планировок и типов, медианы по планировке/типу/премиуму, **сравнение в одинаковом диапазоне** (25-35 кв.м.).
3. **Ценообразование:** влияние метро, возраста, этажа и этажности, района, ЖК.

### `hypothesis_tests.ipynb` - статистические тесты

| Гипотеза | Тест | Почему выбран |
| :--- | :--- | :--- |
| Линейная связь между числовыми | **Пирсон** | стандартный линейный коэффициент |
| Монотонная (в т.ч. нелинейная) связь | **Спирмен** | устойчив к нелинейности и выбросам |
| Различие 2 групп | **Бруннер-Мунцель** | нет ограничения на форму распределения |
| Различие медиан 3+ групп | **Медианный тест Муда** | устойчив к разным формам распределений |
| Какие именно пары групп различаются | **Попарный Бруннер-Мунцель с поправкой Холма** | контроль множественных сравнений |

## Ключевые результаты

### Структура рынка

- **77% однушек**, 23% студий.
- Студии чаще на **вторичном** рынке (55 / 45).

### Формальные результаты гипотез

| Проверяемая гипотеза | Примененный тест и результаты | Полученный вывод |
| :--- | :--- | :--- |
| Различие цен за кв.м. у студий и однушек | Бруннер-Мунцель (W = -10.77, p < 0.05) | **Значимо**. Цена за кв.м. у студий статистически выше, чем у однушек. |
| Различие цен за кв.м. у новостроек и вторички | Бруннер-Мунцель (W = 30.21, p < 0.05) | **Значимо**. Новостройки статистически дороже по цене за кв.м. |
| Связь площади и цены за кв.м. | Пирсон (r = 0.198) / Спирмен (rs = -0.034) на всей выборке. | На всей выборке связь неочевидна. |
| Связь площади и цены за кв.м. (без премиума) | Пирсон (r = -0.039) / Спирмен (rs = -0.077), p < 0.05 | После исключения премиум-сегмента проявилась **слабая отрицательная связь**: чем больше площадь, тем ниже цена за кв.м. |
| Связь возраста дома и цены за кв.м. | Пирсон (r = -0.339) / Спирмен (rs = -0.427), p < 0.001 | **Значимая умеренная связь**. Чем старше дом, тем ниже цена за кв.м. |
| Различие цен за кв.м. между районами | Медианный Муда + попарный Бруннер-Мунцель | **Значимо**. Медианные цены статистически различаются между районами города. |
| Взаимосвязь района и типа жилья | Хи-квадрат (χ²) | **Значимо**. Распределение новостроек и вторички зависит от района (например, в одном районе больше новостроек, в другом - вторички). |
